SaleLedger · Guide

The files behind a trust reconciliation.

What goes into SaleLedger's trust ledger, what your bank has to give you, when an IIF file applies, and the four small things that make your records refuse to line up.

Why not a QuickBooks file? QuickBooks Desktop can import IIF files. Intuit says it can't export transactions as IIF. Auction Flex documents a QuickBooks connector for consignor checks. If you have an .IIF file of your trust account's checks, deposits and transfers (some tools can produce one), use Option A. Otherwise use the ledger template (Option B): a trust ledger CSV plus the bank statement.

1 · The trust ledger CSV (what came in, what went out, what is owed)

This is one spreadsheet saved as CSV, in SaleLedger's format. Download the ledger template. Keep the heading row and delete the four example rows. Then add one row for each money event in the trust account:

  • buyer_receipt: each deposit of buyer money. From your deposit slips or the bank statement.
  • consignor_disbursement: each settlement paid. Gross, commission and net from the settlement sheet; date and check number from the trust checkbook.
  • commission_transfer: each move of commission to the operating account.
  • consignor_settlement_pending: each settlement worked out but not paid yet.

Your Auction Flex settlement report (Consignor Summary #21/#23, Totals by Consignment Order #24/#25, or Totals by Item #26/#27) is a good source for each consignor's gross, commission and net. Run it after the final settlement, not before; figures change when late fees or buybacks post. Every column and allowed value is explained in the how-to.

2 · The trust account bank statement (what the bank saw)

Download it for the full period from online banking as CSV, Excel, or the Quicken / QuickBooks "Web Connect" file (OFX/QFX). Not a PDF: a PDF has no machine-readable dates and amounts, and retyping it is where errors start. Only the trust account: the operating account's statement is not part of this.

Each run takes one ledger and one bank statement. If a month had three auctions, put all three in the ledger; each row keeps its own auction number. An auction you leave out shows up as unexplained deposits and checks.

3 · An IIF file (Option A, only if you already have one)

SaleLedger's Option A takes an Auction Flex settlement export (CSV), an .IIF file of the trust account and the bank statement. If you have an .IIF file of your trust account's checks, deposits and transfers (some tools can produce one), use Option A; otherwise use the ledger template (Option B). SaleLedger matches each IIF check to a consignor by name. It counts only deposits named BUYERS as buyer payments and only transfers named HOUSE as commission transfers. Deposits and transfers with any other name are left out of your records and can show up as unmatched bank lines.
